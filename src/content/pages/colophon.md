I've owned ernestoramirez.com for a long time, and I've never been great at keeping it up to date. This version is built to make writing, and tinkering, easy.

- **Built with** [Astro](https://astro.build). Every page is plain Markdown in a [GitHub repo](https://github.com/erramirez/erramirez.github.io).
- **Edited with** [Pages CMS](https://pagescms.org), which saves every edit as a commit.
- **Hosted on** [Cloudflare](https://workers.cloudflare.com), which rebuilds the site on every push.
- **The SQL box** on the homepage is [SQLite](https://sqlite.org) compiled to WebAssembly with [sql.js](https://sql.js.org). It runs entirely in your browser.
- **Type** is Archivo for headlines, Spectral for reading, IBM Plex Mono for code and data, and Reenie Beanie for notes in the margin.
- **The look** borrows from lab notebooks and risograph printing: graph paper, two inks, and a little misregistration.

The 2014–2017 posts were rescued from the old Hugo and blogdown site, typos and all.
